# Customer Behavior Analysis (SQL Project)

## Project Overview
This project uses SQL to analyze customer behavior data from Miami. The goal is to understand customer patterns and improve business decisions.

## Tools Used
- SQL

## Data Cleaning
- Removed duplicates
- Fixed missing values
- Standardized data

## Analysis
- Customer spending behavior
- Customer segmentation
- Top customers identification

## Conclusion
This project helps understand how customers behave and how businesses can improve marketing and sales strategies.
