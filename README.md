# Customer Behavior Analysis (SQL Project)

## 📊 Project Overview
This project analyzes customer behavior using SQL to understand spending patterns, customer segmentation, and purchasing trends.

The goal is to extract business insights that can help improve marketing strategies and customer retention.

---

## 🗂 Dataset
The dataset contains customer purchase records including:
- Customer demographics (age, gender)
- Purchase amounts
- Product categories
- Subscription status
- Discount usage
- Shipping types

---

## 🛠 Tools Used
- SQL (data analysis)
- GitHub (version control)

---

## 🔍 Key Analyses Performed

### 1. Revenue Analysis
- Total revenue by gender
- Revenue by subscription status
- Revenue by age group

### 2. Customer Behavior
- Discount usage patterns
- Purchase frequency analysis
- Repeat buyer analysis

### 3. Customer Segmentation
- New customers
- Returning customers
- Loyal customers

### 4. Product Insights
- Top-selling items per category
- Product rating analysis
- Discount rate by product

---

## 💡 Key Insights
- Certain customer groups contribute significantly more revenue than others
- Loyal customers generate the highest long-term value
- Discounts influence purchasing behavior differently across products
- Subscription status is strongly linked to higher average spending

---

## 📌 Conclusion
This project demonstrates how SQL can be used to analyze customer behavior and generate actionable business insights that support decision-making in marketing and sales strategy.
